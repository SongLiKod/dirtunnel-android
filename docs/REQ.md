# DirTunnel - 安卓多协议目录服务 & 内网穿透工具
仓库：dirtunnel-android

## 一、项目概述
### 1.1 项目背景
市面安卓端文件服务、内网穿透工具大多功能割裂：单一协议、固定共享目录、穿透配置复杂、后台容易被杀、权限管控简陋。本项目目标是在安卓手机上，让用户自由选择任意目录，为目录启动多种文件服务协议，并集成内网穿透，实现局域网/外网访问。兼顾普通用户文件共享、开发者调试、运维备份场景。

### 1.2 核心目标
1. 支持自由选择安卓任意目录，每个目录可独立启动一套或多套服务；
2. 内置多文件服务协议，独立端口、独立账号、独立权限；
3. 集成内网穿透，公共隧道一键使用 + 自建FRP隧道模式；
4. 深度适配安卓后台保活，解决息屏断连；
5. 界面支持浅色 / 深色 / 跟随系统主题，体验统一；
6. 纯净无广告、低功耗、轻量化。

### 1.3 适用场景
- 局域网文件共享、手机文件夹挂载为网络磁盘
- 开发调试：HTTP静态服务外网预览
- 远程备份、跨设备同步文件
- 临时对外分发文件资源

## 二、同类软件调研与优缺点总结
> 原始调研内容不变，新增WebDAV相关对比
1. Primitive ftpd：FTP/SFTP轻量，但是目录固定、缺少WebDAV/HTTP，无穿透
2. FTP Tool：支持FTP/FTPS/HTTP，缺少SFTP、WebDAV，穿透能力弱
3. AndFTP：仅客户端，不能做服务端
4. 花生壳：穿透稳定但收费，无内置文件服务
5. FRP安卓端：免费可控，但纯命令行，上手难，无内置文件服务

**痛点汇总**
- 服务和穿透工具分离，多APP切换麻烦
- 共享目录固定，不能任意选择文件夹
- 协议不全，缺少WebDAV、SMB等刚需协议
- 安卓后台保活差，息屏隧道断开
- 权限全局开放，缺少单目录精细化权限
- 要么付费限速，要么门槛极高

## 三、协议规划（按版本优先级）
### V1.0（首发，最高优先级）
- FTP
- FTPS (FTP+TLS)
- SFTP
- HTTP（静态网页浏览下载）
- WebDAV + WebDAV over HTTPS

### V1.1（迭代）
- SMB2/SMB3（Samba，默认关闭SMB1）
- HTTPS 自定义证书（自签/导入证书）

### V1.2（高阶功能，默认隐藏）
- Rsync 增量同步服务端
- NFS（Linux挂载，高级选项，默认关闭）

### 穿透层独立能力（不局限内置协议）
支持自定义本地TCP端口转发：用户可以启动APP以外的本地服务，通过DirTunnel的FRP隧道转发出去。

## 四、核心功能需求
### 4.1 目录管理（差异化核心）
1. 浏览、选择手机任意目录：内部存储、SD卡、可访问分区；适配Android SAF存储访问框架；
2. 目录收藏，一键复用；
3. 一个目录可以同时绑定多个协议实例，每个协议独立端口、账号、权限、穿透开关；
4. 权限：只读 / 读写 / 禁止删除。

### 4.2 服务实例管理
每个协议实例属性：
- 绑定目录
- 协议类型
- 监听端口
- 账号密码（支持匿名，匿名开关独立）
- 权限配置
- 是否启用穿透
- 是否自动启动

支持：一键启动、停止、重启、查看状态。

### 4.3 内网穿透模块
两种模式：
1. 公共隧道：内置服务，一键穿透，生成外网访问地址+二维码；
2. 自建FRP服务端：填写服务器地址、端口、token，图形化配置，无需手写ini；
隧道兼容TCP，适配所有内置协议 + 用户自定义端口。

### 4.4 安全与审计
- IP白名单
- 连接日志、上传下载日志，支持导出
- 所有加密协议使用现代加密套件（TLS1.2/1.3、SSH2）
- 配置文件本地加密存储
- 端口自定义，避免默认端口风险

### 4.5 UI主题需求
支持三种模式：跟随系统、浅色模式、深色模式
> 详细色值规范见技术文档

### 4.6 监控
首页仪表盘：服务运行状态、在线连接数、实时流量、隧道状态、端口占用告警、权限不足告警。

## 五、非功能需求
### 性能
- 单服务启动 <1s；
- 后台稳定运行 ≥72h，息屏保活优化；
- APK体积控制，V1.0目标 ≤15MB；
- 内存占用峰值 ≤200MB。

### 兼容性
Android 8.0 ~ Android 15；适配SAF分区存储；WiFi / 蜂窝网络 / 热点。

### 安全
- 不上传用户文件；
- 不私自收集文件；
- 所有隧道配置用户可控；
- 一键清空日志、关闭全部服务。

### 易用性
核心流程：选择目录 → 添加协议服务 →（可选开启穿透）三步完成。异常提示附带解决方案（端口占用、SAF权限、后台电池限制）。

## 七、项目差异化亮点
1. 一体化：目录管理 + 多协议文件服务 + FRP穿透在同一个APP；
2. 灵活：目录与协议解耦，单目录多协议独立配置；
3. 兼顾小白（一键公共隧道）和开发者（自建FRP、自定义TCP转发）；
4. 原生主题支持浅色/深色/跟随系统；
5. 纯净无广告。
